Format attendu

Une ligne par opération, avec ces colonnes (le séparateur ; ou , est reconnu tout seul) :

datetypetickerquantiteprixfrais
2024-03-15achatSAN.PA1092,501,90
15/03/2025venteKO561.200
  • La date s'écrit AAAA-MM-JJ ou JJ/MM/AAAA. Le type est « achat » ou « vente » (ou buy / sell).
  • Le ticker est le symbole Yahoo Finance (SAN.PA, KO, BRK-B…). L'ISIN est aussi accepté pour les titres du dictionnaire.
  • La colonne « frais » est facultative. Les virgules décimales sont acceptées.
  • Tout ou rien : si une ligne est invalide, rien n'est enregistré. Réimporter le même fichier ne crée pas de doublons.
